# E2E-проверки

Это воспроизводимые сценарии приёмки, а не отчёт о выполненных прогонах.

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Получение структурированного совета по PR | Доступен `POST /api/reviews`; подготовлен учебный diff не длиннее 20 000 символов без реальных секретов | Отправить один запрос с diff | Ответ содержит `summary`, массив `risks`, массив `checks`; в `risks` не более трёх элементов, каждый имеет `file`, `line`, `evidence`, `risk` | `CASE.md`: OUT-1 |
| Исключение неподтверждённого риска | В тестовом ответе LLM есть риск без ссылки на строку diff и без релевантного правила | Отправить запрос и получить итоговый ответ сервиса | Неподтверждённый риск отсутствует в `risks` | `CASE.md`: QA-1 |
| Сохранение риска, подтверждённого строкой diff | В diff есть уникальная строка, на которую ссылается тестовый риск | Отправить запрос и получить итоговый ответ | Риск может быть включён и содержит ссылку на эту строку в `evidence` | `CASE.md`: QA-1, OUT-1 |
| Сохранение риска, подтверждённого правилом | Тестовый риск ссылается на релевантное правило репозитория | Отправить запрос и получить итоговый ответ | Риск может быть включён с правилом в `evidence` | `CASE.md`: QA-1, OUT-1 |
| Приём diff длиной 19 999 символов | Доступен API; подготовлен diff ровно из 19 999 символов | Отправить один запрос | Запрос не отклонён с HTTP 413 из-за размера; при сформированном ответе действует OUT-1 | `CASE.md`: API-1, OUT-1 |
| Приём diff длиной 20 000 символов | Доступен API; подготовлен diff ровно из 20 000 символов | Отправить один запрос | Запрос не отклонён с HTTP 413 из-за размера; при сформированном ответе действует OUT-1 | `CASE.md`: API-1, OUT-1 |
| Отклонение diff длиной 20 001 символ | Доступен API; подготовлен diff ровно из 20 001 символа; включено наблюдение вызова LLM | Отправить один запрос | API возвращает HTTP 413; внешний LLM не вызывается | `CASE.md`: API-1 |
| Удаление тестовых секретов до внешнего вызова | Diff содержит уникальные тестовые токен, пароль и приватный ключ; граница LLM наблюдается через spy/mock | Отправить один запрос | Ни один исходный секрет не присутствует во входе внешнего LLM | `CASE.md`: SEC-1 |
| Ограничение медленного внешнего вызова | LLM-test-double не отвечает дольше 10 секунд | Отправить один допустимый diff | Внешний вызов прекращается по timeout 10 секунд; сервис возвращает контролируемый ответ. Точные код и JSON-схема неизвестны и требуют решения человека | `CASE.md`: REL-1 |
| Обработка ошибки внешнего LLM | LLM-test-double возвращает ошибку | Отправить один допустимый diff | Сервис возвращает контролируемый ответ без необработанной ошибки; точный контракт неизвестен | `CASE.md`: REL-1 |
| Сервис остаётся советующим | Включено наблюдение доступных внешних зависимостей | Отправить запрос и завершить получение ответа | Получен только совет; запись кода, approve и merge не инициированы | `CASE.md`: SCOPE-1 |
| Безопасная запись журнала | Diff и ответ LLM содержат разные уникальные маркеры; доступен журнал запроса | Отправить запрос и найти запись по `request_id` | В записи есть только `request_id`, длительность и статус; маркеры diff и ответа отсутствуют | `CASE.md`: OBS-1 |
