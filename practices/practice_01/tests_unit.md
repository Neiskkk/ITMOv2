# Unit-проверки

Проверки ниже описывают изолируемое поведение, а не неподтверждённые имена функций или классов. Фактические тесты не запускались: это план покрытия для будущей реализации.

| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Evidence |
|---|---|---|---|---|
| OUT-1 | Обязательные верхнеуровневые поля результата | Результат без `summary`, `risks` или `checks` | Результат отклонён как не соответствующий контракту; механизм отклонения не задан | `CASE.md`: OUT-1 |
| OUT-1 | Ограничение количества рисков | Результат с четырьмя рисками | Результат не принимается как соответствующий OUT-1, пока `risks` содержит больше трёх элементов | `CASE.md`: OUT-1 |
| OUT-1 | Поля одного риска | Риск без одного из полей `file`, `line`, `evidence`, `risk` | Риск не включается в контрактный результат | `CASE.md`: OUT-1 |
| QA-1 | Риск подтверждён строкой diff | Риск со ссылкой на конкретную строку входного diff | Риск допускается к включению при соблюдении OUT-1 | `CASE.md`: QA-1, OUT-1 |
| QA-1 | Риск подтверждён правилом репозитория | Риск со ссылкой на идентификатор релевантного правила | Риск допускается к включению при соблюдении OUT-1 | `CASE.md`: QA-1 |
| QA-1 | Неподтверждённый риск | Риск без строки diff и без правила репозитория | Риск не включается в ответ | `CASE.md`: QA-1 |
| SEC-1 | Удаление тестового токена | Diff с уникальным тестовым токеном | Во входе внешнего LLM отсутствует исходный токен | `CASE.md`: SEC-1 |
| SEC-1 | Удаление тестового пароля | Diff с уникальным тестовым паролем | Во входе внешнего LLM отсутствует исходный пароль | `CASE.md`: SEC-1 |
| SEC-1 | Удаление тестового приватного ключа | Diff с тестовым приватным ключом | Во входе внешнего LLM отсутствует исходный ключ | `CASE.md`: SEC-1 |
| API-1 | Допустимое значение ниже границы | Diff длиной 19 999 символов | Проверка размера принимает вход; дальнейший HTTP-результат этим unit-сценарием не определяется | `CASE.md`: API-1 |
| API-1 | Допустимое граничное значение | Diff длиной 20 000 символов | Проверка размера принимает вход; дальнейший HTTP-результат этим unit-сценарием не определяется | `CASE.md`: API-1 |
| API-1 | Значение выше границы | Diff длиной 20 001 символ | Проверка размера отклоняет вход; API должен сопоставить это с HTTP 413, конкретный внутренний механизм неизвестен | `CASE.md`: API-1 |
| REL-1 | Ограничение внешнего вызова | LLM-зависимость не отвечает дольше 10 секунд | Внешний вызов прекращается по timeout 10 секунд | `CASE.md`: REL-1 |
| REL-1 | Преобразование ошибки зависимости | LLM-зависимость возвращает ошибку | Ошибка преобразуется в контролируемый ответ; точные код и схема неизвестны | `CASE.md`: REL-1 |
| SCOPE-1 | Результат остаётся советом | Сформированный результат ревью | Не инициируются запись кода, approve или merge; способ наблюдения зависит от реализации | `CASE.md`: SCOPE-1 |
| OBS-1 | Разрешённые поля записи журнала | Событие завершения запроса | Запись содержит только `request_id`, длительность и статус | `CASE.md`: OBS-1 |
| OBS-1 | Запрещённое содержимое записи журнала | Событие с уникальными маркерами в diff и ответе модели | В записи отсутствуют оба уникальных маркера | `CASE.md`: OBS-1 |

Неизвестными остаются имена и интерфейсы изолируемых компонентов, тип ошибки валидатора и точный контракт контролируемого ответа REL-1.
