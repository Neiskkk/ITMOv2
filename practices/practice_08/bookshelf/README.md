# Книжная полка

Практика 8. Читатель сохраняет название книги и автора и возвращается к списку позже. Основной сценарий проходит через диалог добавления до карточки на полке. Данные остаются после перезагрузки страницы и перезапуска приложения.

[Прототип Figma Make](https://www.figma.com/make/3I19ttIHNYVqmSmx83Jeg6/) · [Отчёт со скриншотами](REPORT.md) · [Исходный запрос к Figma](../FIGMA.md)

## Запуск в Ubuntu

Из корня репозитория, Node.js 22.12+ или 24 и npm.

```sh
cd practices/practice_08/bookshelf
npm ci
npm run dev
```

Открыть локальный адрес из терминала. React, TypeScript, Tailwind CSS и компоненты в стиле shadcn/ui из экспорта Figma Make. Диалог и меню используют Radix UI. Все шрифты входят в сборку. Общая тема и шаг отступов заданы в `src/index.css`.

API доступен через Vite в режимах dev и preview. GET /api/books возвращает массив, POST принимает объект с title и author и возвращает созданную книгу с id и статусом 201. Для одного локального сервера данные хранятся в .data/books.json. При необходимости каталог задаётся через BOOKS_DATA_DIR.

## Проверки

```sh
npx playwright install --with-deps chromium
npm test
npx tsc --noEmit
npm run build
npm run preview
```

При уже установленном Chromium можно указать путь через CHROMIUM_PATH. Команда `CAPTURE_EVIDENCE=1 npm test` обновляет скриншоты в report/screens. Тестовый сервер использует временное хранилище. Рабочая полка хранится отдельно.

## Демонстрация

Открыть «Добавить книгу», заполнить поля и сохранить. Перезагрузить страницу и проверить карточку. Меню «Демонстрация» позволяет показать пустую полку и одноразовый сбой. При настоящем сбое API форма также сохраняет введённые данные. В тесте ожидания серверный ответ задерживается до завершения проверок, поэтому двойной клик и Enter можно воспроизвести без зависимости от скорости машины.
