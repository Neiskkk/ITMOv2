# Рефлексия

Больше всего мне помог `AGENTS.md`: с ним агент сразу понимал структуру проекта, ограничения и команду проверки. Skill `frontend-design` пригодился при выборе цветов, типографики и внешнего вида карточек, а Playwright MCP позволил проверить страницу через настоящий пользовательский сценарий.

Самой сложной частью оказался hook. Сначала он не загружался, потом запускался не из того каталога, поэтому результат автоматической проверки не возвращался агенту. Пришлось разобраться с путями, форматом плагина OpenCode 2 и отдельно проверить сценарии `FAIL` и `PASS`.

Worktree оказался полезным для второй фичи: изменения формы не смешивались с основной веткой, а отдельный review через `@explore` нашёл две конкретные проблемы. Я решила сохранить собственные сообщения валидации и использовать браузерную Constraint Validation API вместе с JavaScript-проверкой.

При создании собственного MCP я лучше поняла разницу между подключённым сервером и настоящим вызовом tool. Для сдачи важно показать не статус `connected`, а конкретный полезный результат и обработку ошибочного ввода.
