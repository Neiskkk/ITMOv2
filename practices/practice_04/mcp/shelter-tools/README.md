# shelter-tools MCP

Локальный stdio MCP-сервер для проверки заявки на знакомство с питомцем.

## Tool

`validate_application` проверяет идентификатор питомца, имя заявителя, телефон или email, длину комментария и согласие на обработку данных. Корректная заявка возвращает `valid: true`. Некорректная заявка возвращает `isError: true` и объект `errors` с понятными сообщениями по полям.

## Проверка

```bash
npm install
npm run check
```

OpenCode запускает сервер автоматически по настройке `shelter-tools` в корневом `opencode.json`.
