# catalog/pet-name-search Specification

## Purpose
Добавить поиск по имени питомца в каталоге, чтобы пользователи могли быстро находить карточки по части имени, без учёта регистра, совместно с фильтрами вида животных.

## Requirements

### Requirement: Поле поиска по имени
Секция каталога SHALL содержать видимое поле ввода для поиска по имени, расположенное над группой фильтров и имеющее подпись «Поиск по имени» и placeholder «Начните вводить имя».

#### Scenario: Поле доступно на странице
- **WHEN** пользователь открывает секцию «Питомцы»
- **THEN** он видит поле «Поиск по имени» над фильтрами и может фокусировать его с клавиатуры

### Requirement: Совпадение по подстроке без учёта регистра
Система SHALL отфильтровывать карточки по подстроке имени без учёта регистра на каждой смене значения поля поиска.

#### Scenario: Совпадение по подстроке
- **WHEN** пользователь вводит «на»
- **THEN** отображаются только карточки, в имени которых содержится «на» в любом регистре

#### Scenario: Нечувствительность к регистру
- **WHEN** пользователь вводит «БУ»
- **THEN** отображаются карточки с именами, содержащими «бу», «Бу», «БУ» и т.п.

### Requirement: Комбинация с фильтрами вида (AND)
Система SHALL применять поиск по имени совместно с выбранным фильтром вида животных по правилу AND.

#### Scenario: AND с фильтром «Кошки»
- **WHEN** выбран фильтр «Кошки» и введён запрос «на»
- **THEN** отображаются только кошки, чьи имена содержат «на»

### Requirement: Очистка поиска восстанавливает текущий фильтр
Очистка поля SHALL немедленно восстанавливать список карточек по текущему фильтру вида без дополнительного действия.

#### Scenario: Очистка поля
- **WHEN** пользователь очищает поле (удаляет введённый текст)
- **THEN** отображаются результаты текущего фильтра вида (Все/Кошки/Собаки)

### Requirement: Пустое состояние при отсутствии совпадений
При отсутствии совпадений система SHALL скрывать карточки и отображать существующее сообщение пустого состояния каталога.

#### Scenario: Нет совпадений
- **WHEN** введён запрос, для которого нет совпадений с выбранным фильтром вида
- **THEN** карточки не отображаются и показывается существующее пустое состояние

### Requirement: Кнопка «Познакомиться» работает из отфильтрованного списка
Кнопка «Познакомиться» SHALL продолжать выбирать правильного питомца, прокручивать страницу к форме и переводить фокус на первое поле формы независимо от активного поиска/фильтра.

#### Scenario: Переход к форме из результатов поиска
- **WHEN** пользователь нажимает «Познакомиться» на карточке, показанной при активном поиске
- **THEN** в форме выбран соответствующий питомец, секция «Заявка» прокручивается в область видимости, а фокус переходит на поле имени
