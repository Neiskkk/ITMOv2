# Proposal

## Why

Пользователь выбирает фильтр «Все / Кошки / Собаки» каждый раз при открытии страницы. Запоминание последнего выбранного фильтра в браузере сократит лишние действия и ускорит доступ к интересующим карточкам без влияния на приватность.

## What Changes

- Сохранять выбранный фильтр вида («all», «cat», «dog») в localStorage при переключении.
- На старте страницы восстанавливать фильтр из localStorage.
- При неизвестном/повреждённом значении использовать «all».
- Не сохранять поисковый запрос и любые персональные данные.
- Сохранить работу поиска по имени, счётчиков, формы заявки и кнопки «Познакомиться».
- Без backend и сетевых запросов.

## Impact

- JS: обработка сохранения/восстановления фильтра, валидация значений, неизменность поведения поиска, счётчиков и формы.
- HTML/CSS: без изменений UI; фильтры остаются прежними.
- Без внешних зависимостей и сетевых запросов; локальное хранилище браузера.
