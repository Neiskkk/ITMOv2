# Spec Delta

## Purpose

Запоминать и восстанавливать фильтр вида («Все / Кошки / Собаки») между сессиями пользователя, не затрагивая поиск, форму и счётчики.

## ADDED Requirements

### Requirement: Сохранение выбранного фильтра в localStorage
Система SHALL сохранять значение выбранного фильтра вида при переключении в localStorage под стабильным ключом.

#### Scenario: Сохраняется поддерживаемое значение
- **WHEN** пользователь выбирает фильтр «Кошки»/«Собаки»/«Все»
- **THEN** в localStorage сохраняется соответственно значение "cat"/"dog"/"all"

### Requirement: Валидация и безопасное восстановление
Система SHALL при инициализации каталога читать значение из localStorage и применять его только если оно равно "all", "cat" или "dog"; иначе использовать "all".

#### Scenario: Неизвестное или повреждённое значение
- **WHEN** в localStorage находится неизвестное значение (например, "birds") или нестроковое содержимое
- **THEN** активируется фильтр "all" и значение в каталоге не ломает работу

### Requirement: Изоляция приватных данных и поиска
Система SHALL не сохранять поисковый запрос, персональные данные формы или другие поля; в localStorage хранится только вид фильтра.

#### Scenario: Поиск не сохраняется
- **WHEN** пользователь вводит запрос в поле поиска и перезагружает страницу
- **THEN** поле поиска пустое, а в localStorage отсутствует значение запроса

### Requirement: Совместимость с существующими функциями
Система SHALL сохранять текущую работу поиска по имени, счётчиков, формы заявки и кнопки «Познакомиться».

#### Scenario: Непрерывность поведения
- **WHEN** пользователь выбирает фильтр, выполняет поиск и нажимает «Познакомиться»
- **THEN** поведение совпадает с принятым ранее: правильный питомец выбран, прокрутка и фокус работают, счётчики не ломаются
