# Proposal

## Why

Каталог сейчас позволяет фильтровать по виду (все/кошки/собаки), но нельзя быстро найти питомца по имени. Это замедляет выбор и увеличивает когнитивную нагрузку при большом списке. Добавление поиска по имени ускорит переход к нужной карточке и повысит вероятность валидной заявки без перезагрузки.

## What Changes

- Добавить в секцию каталога поле «Поиск по имени» над кнопками фильтра.
- Выполнять фильтрацию по подстроке имени без учёта регистра, совместно с выбранным видом животного (AND).
- Обновлять результаты сразу при каждом изменении значения.
- При очистке поля показывать результаты текущего фильтра вида.
- Использовать существующее пустое состояние при отсутствии совпадений.
- Сохранить текущее поведение фильтров, счётчиков, карточек и формы заявки без изменений.

## Capabilities

### New Capabilities
- catalog/pet-name-search: Возможность искать питомцев в каталоге по части имени, с нечувствительностью к регистру и совместной работой с фильтрами вида.

## Impact

- UI: index.html (добавление поля поиска), styles.css (минимальные стили, совместимые с существующей группой фильтров).
- JS: script.js — расширение рендеринга каталога с учётом поискового запроса и привязка события ввода.
- Доступность: видимая подпись поля, клавиатурная доступность сохранена; aria-live у каталога остаётся без изменений.
- Без внешних зависимостей, без сетевых запросов, без изменений структуры данных животных.
