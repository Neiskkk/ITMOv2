# Design

## Context

Каталог уже реализует фильтры по виду животных через кнопки «Все», «Кошки», «Собаки». Рендер карточек и пустого состояния инкапсулирован в renderAnimals(filter). Карточки создаются безопасно (DOM API), кнопка «Познакомиться» вызывает openApplication(animalId). Счётчики видов обновляются отдельно и не зависят от текущего рендера.

## Goals / Non-Goals

**Goals:**
- Добавить поиск по имени без учёта регистра и по подстроке.
- Совместная работа с фильтрами вида по правилу AND.
- Живое обновление результатов при каждом изменении ввода и восстановление текущего фильтра при очистке.
- Сохранить существующие счётчики, пустое состояние, фокус и прокрутку при «Познакомиться».

**Non-Goals:**
- Поиск по описанию/возрасту/полу.
- Изменение структуры данных животных.
- Добавление backend, сетевых запросов, сохранения состояния или новой кнопки сброса.

## Decisions

- Поле поиска размещается над группой фильтров в секции каталога, с подписью «Поиск по имени» и placeholder «Начните вводить имя».
- Фильтрация имен: toLowerCase() по имени и по введённому значению; простая подстрока String.includes().
- Семантика: AND — сначала фильтр вида (существующий), затем дополнительная фильтрация по имени.
- Событие: input (live search). Очистка поля (value === "") немедленно возвращает результат текущего фильтра без дополнительных действий.
- Архитектура: не модифицировать animals и filterAnimals; расширить renderAnimals так, чтобы она учитывала текущее значение поиска. Обработчик ввода вызывает перерисовку с активным фильтром (читается из DOM — кнопка .is-active / aria-pressed=true), без глобального состояния.
- Доступность: явная связка label+input; поле входит в таб-цикл; фокус-стили уже заданы глобально.

Альтернативы, рассмотренные:
- Дебаунс ввода: не требуется для данного объёма данных; можно добавить позже при росте списка.
- toLocaleLowerCase('ru'): базовый toLowerCase достаточен; вернёмся к локали при выявлении кейсов.

## Risks / Trade-offs

- Производительность при очень длинных списках: текущий размер мал, но при росте стоит добавить дебаунс/ограничение частоты рендера.
- Локализация регистров для смешанных алфавитов: при потребности перейти на toLocaleLowerCase().
- Регрессия пустого состояния: тестировать сценарии «нет совпадений» в сочетании с фильтрами вида.

## Migration Plan

- Изменения атомарны и обратимы. При проблемах — откат PR.
- Проверить node --check и ручные сценарии на 320 / 768 / 1440 px.
- Проверить клавиатурную навигацию и поведение «Познакомиться» из результатов поиска.
