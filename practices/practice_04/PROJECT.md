# Практика 4 — «Лапа помощи»

Одностраничный учебный лендинг вымышленного приюта для животных. Стек: HTML5, CSS3 и vanilla JavaScript без внешних зависимостей.

## Текущий этап

Реализована **Feature 1**:

- каталог из шести питомцев;
- фильтры «Все», «Кошки», «Собаки»;
- карточки, создаваемые из локального массива JavaScript;
- выбор питомца и переход к черновику заявки;
- адаптивная и клавиатурно доступная навигация.

Feature 2 пока не реализована: форма показана только как черновой блок, необходимый для проверки передачи выбранного питомца.

## Запуск

Из каталога `practices/practice_04`:

```bash
python3 -m http.server 8000
```

Открыть в браузере: <http://localhost:8000>

## Статическая проверка

```bash
node --check script.js
```

## Ручная приёмка Feature 1

- При первом открытии отображаются все 6 карточек и активен фильтр «Все».
- «Кошки» показывают 3 кошек, «Собаки» — 3 собак.
- Возврат к «Все» не создаёт дубликаты.
- Фильтры работают мышью и клавишами Enter/Space.
- Активная кнопка имеет `aria-pressed="true"`.
- Каждая карточка содержит изображение, имя, вид, возраст, пол, описание и кнопку.
- «Познакомиться» выбирает правильного питомца, прокручивает страницу к заявке и переводит фокус в поле имени.
- На ширинах 320, 768 и 1440 px отсутствует горизонтальная прокрутка.
