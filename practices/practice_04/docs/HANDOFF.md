# HANDOFF — итог по practice_04

Краткая сводка состояния проекта и дальнейших шагов.

## Реализовано

- Feature 1 — каталог и фильтрация животных:
  - Данные животных хранятся в массиве объектов в script.js (6 карточек: кошки и собаки).
  - Инициализация каталога: счётчики по видам, начальный фильтр «Все», отрисовка карточек без перезагрузки.
  - Переключение фильтров «Все/Кошки/Собаки» обновляет список; активный фильтр помечается классом и aria-pressed.
  - Пустое состояние показывается при отсутствии результатов.
  - Кнопка «Познакомиться» передаёт выбранного питомца в форму: выполняется прокрутка к секции заявки и фокус на первое поле.

- Feature 2 — форма заявки на знакомство:
  - Поля: выбор питомца, имя, телефон, email, комментарий, согласие.
  - Клиентская валидация: имя 2–60 символов, телефон (разрешённые символы, ≥10 цифр) или email (браузер + простая проверка), комментарий ≤500 символов, согласие обязательно.
  - Ошибки выводятся рядом с полями, поля помечаются aria-invalid и связаны через aria-describedby; фокус переходит на первое невалидное поле.
  - Успешная отправка: без сетевого запроса, показывается статус «Заявка принята. Мы свяжемся с вами», персональные поля очищаются, выбранный питомец сохраняется.

## Важные ограничения проекта

- Один HTML (index.html), один CSS (styles.css), один JS (script.js); без сборки и фреймворков.
- Без backend, БД и внешних API; локальный запуск через статический сервер.
- Русский интерфейс; демонстрационные данные и локальные изображения.
- Не сохранять персональные данные (ни в хранилище браузера, ни в URL); не выполнять сетевые запросы.
- Не использовать inline JS, eval, и небезопасные вставки innerHTML для пользовательских данных.
- Доступность: семантическая разметка, связки label↔field, aria-атрибуты, видимый focus.
- Адаптивность: mobile-first; поддержка от 320 px; отсутствие горизонтальной прокрутки.
- Не изменять файлы вне practices/practice_04 и не добавлять зависимости без согласования.
