# Разбор frontend-design

Я выбрала skill `frontend-design`, потому что он помогает продумать внешний вид сайта до написания кода. В нём есть советы по выбору цветов, шрифтов, сетки и общего стиля страницы. В своём проекте я использовала эти рекомендации для карточек животных, цветовых переменных и адаптивной вёрстки. Результат я проверила в браузере с помощью Playwright MCP.
