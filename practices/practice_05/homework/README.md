## 10. Сравнение Spec Kit и OpenSpec (кратко)
- GitHub Spec Kit: конвейер — constitution → specify → plan → tasks → implement. Удобнее для полного проектирования фичи и командной декомпозиции.
- OpenSpec: жизненный цикл — proposal/spec/design/tasks → apply → sync → archive. Постоянные правила OpenSpec задавались через config.yaml. Удобнее для жизненного цикла отдельного изменения и архивирования.
